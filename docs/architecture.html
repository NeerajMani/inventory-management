Technology Stack

Frontend

  • Framework: Vue 3
  • API: Composition API
  • Build Tool: Vite
  • HTTP Client: Axios
  • Routing: Vue Router
  • Port: 3000

Backend

  • Framework: FastAPI
  • Server: Uvicorn
  • Validation: Pydantic
  • CORS: FastAPI Middleware
  • Port: 8001

Data Storage

  • Type: In-Memory (Demo)
  • Format: JSON Files
  • Loader: mock_data.py
  • Persistence: None (restarts reload)

Development

  • Package Manager: npm, pip
  • Testing: pytest, FastAPI TestClient
  • Version Control: Git
  • CI/CD: GitHub Actions

Data Flow

1
User Interaction User interacts with Vue components, applies filters (warehouse, category, status, time period)
2
API Request Vue component calls api.js function with filters, which constructs URL query parameters
3
HTTP Request Axios sends GET/POST request to FastAPI backend at http://localhost:8001/api
4
Backend Processing FastAPI route receives request, applies filters using filter functions, validates with Pydantic models
5
Data Retrieval Backend accesses in-memory data (loaded from JSON files at startup via mock_data.py)
6
Response Filtered and validated data returned as JSON response to frontend
7
Rendering Vue component stores data in refs, computed properties derive display values, UI updates reactively
